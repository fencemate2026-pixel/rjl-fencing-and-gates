# Business claims that require evidence

- On 3 November 2026, Jazz confirmed that RJL is **not VBA registered**. Do not claim VBA registration in visible copy, metadata, structured data, article text, images or downloadable material. Accurate links to the regulator and explanations of project-specific legal requirements are allowed; they do not establish RJL registration.
- Never invent licences, ISO certification, manufacturer certification, approved-contractor status, insurance limits, testimonials, prices, savings or results. A statement already on a website is not independent evidence for a credential.
- Keep an identifiable owner-supplied record or authoritative source for a credential before adding or renewing a claim. The broader audit has flagged existing ISO/manufacturer/approval claims for evidence review; no independent certification check is claimed.
- Every user-facing progress update and final report must identify its actual sources. Separate verified observations, recommendations and unverified matters.

## Repository maintenance

Commit source changes, meaningful tests, README updates and relevant documentation to this site's own GitHub repository. Keep work reviewable, refresh the production branch before integrating changes and avoid overwriting concurrent edits. Report whether a change is prepared, committed, merged or verified live.
